\chapter{Resumen}
En la actualidad, las infraestructuras de red presentan un grado creciente de complejidad debido a la diversidad de dispositivos y servicios que las componen. Esta situación exige herramientas avanzadas que permitan supervisar el estado de la red en tiempo real, detectar incidencias de manera temprana y facilitar la toma de decisiones por parte de los administradores.

El siguiente Trabajo Final de Máster aborda el diseño e implementación de un sistema web de monitorización de red con capacidad de detección de anomalías. El objetivo principal es desarrollar una plataforma integral que permita obtener información relevante de los dispositivos de red, analizar su comportamiento y representar los resultados en una interfaz visual clara e interactiva.

La solución se ha desarrollado siguiendo una arquitectura cliente-servidor. El \textit{backend}, implementado en Python mediante el framework FastAPI\footnote{FastAPI: Framework moderno de Python para la creación de APIs web. Disponible en: \url{https://fastapi.tiangolo.com}}, establece conexión con routers Cisco del emulador GNS3\footnote{GNS3: Emulador de redes que permite simular routers y switches reales. Disponible en: \url{https://www.gns3.com}} utilizando el protocolo SSH\footnote{SSH: Protocolo seguro de administración remota definido en la RFC 4251.} a través de la librería Paramiko\footnote{Paramiko: Librería de Python para realizar conexiones SSH programáticas. Disponible en: \url{https://www.paramiko.org}} para extraer métricas como el estado de las interfaces, el tráfico de entrada y salida, la utilización de CPU y memoria, así como los cambios de configuración en los dispositivos. Por su parte, el \textit{frontend} se ha construido con Vue.js\footnote{Vue.js: Framework progresivo de JavaScript para interfaces interactivas. Disponible en: \url{https://vuejs.org}}, Bootstrap\footnote{Bootstrap: Framework CSS para diseño web responsivo. Disponible en: \url{https://getbootstrap.com}} y Chart.js\footnote{Chart.js: Librería JavaScript para la creación de gráficos en HTML5. Disponible en: \url{https://www.chartjs.org}}, ofreciendo una visualización dinámica de los datos mediante gráficos en tiempo real, tablas interactivas y barras de progreso que facilitan la interpretación de los parámetros monitorizados.

Además, el sistema incorpora mecanismos de seguridad y gestión de usuarios mediante autenticación basada en JSON Web Tokens (JWT)\footnote{JSON Web Tokens (JWT): Estándar abierto para autenticación segura. Disponible en: \url{https://jwt.io}}, lo que garantiza el acceso restringido a la aplicación. También se ha implementado un módulo de generación automática de informes en formato PDF y su envío por correo electrónico en caso de detección de errores.

Los resultados obtenidos evidencian que la solución propuesta cumple los objetivos planteados: permite monitorizar en tiempo real distintos dispositivos de red, detectar anomalías en su funcionamiento y presentar la información de forma accesible y comprensible. Este sistema constituye una herramienta de apoyo útil para la gestión de redes de telecomunicaciones, con potencial de aplicación hacia entornos más complejos.
