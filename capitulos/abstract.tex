\chapter{Abstract}
In today's context, network infrastructures present an increasing degree of complexity due to the diversity of devices and services they encompass. This situation requires advanced tools capable of continuously supervising the network status in real time, detecting incidents at an early stage, and facilitating decision-making for administrators.  

This Master's Thesis addresses the design and implementation of a web-based network monitoring system with anomaly detection capabilities. The main objective is to develop an integrated platform that enables the retrieval of relevant information from network devices, the analysis of their behavior, and the representation of results through a clear and interactive visual interface.  

The solution has been developed following a client-server architecture. The \textit{backend}, implemented in Python using the FastAPI framework\footnote{FastAPI: Modern Python framework for building web APIs. Available at: \url{https://fastapi.tiangolo.com}}, connects to Cisco routers within the GNS3 emulator\footnote{GNS3: Network emulator that allows the simulation of real routers and switches. Available at: \url{https://www.gns3.com}} via the SSH protocol\footnote{SSH: Secure Shell protocol for remote administration, defined in RFC 4251.} through the Paramiko library\footnote{Paramiko: Python library for establishing SSH connections programmatically. Available at: \url{https://www.paramiko.org}} to extract metrics such as interface status, inbound and outbound traffic, CPU and memory utilization, as well as configuration changes in the devices. The \textit{frontend}, developed with Vue.js\footnote{Vue.js: Progressive JavaScript framework for building interactive user interfaces. Available at: \url{https://vuejs.org}}, Bootstrap\footnote{Bootstrap: CSS framework for responsive web design. Available at: \url{https://getbootstrap.com}}, and Chart.js\footnote{Chart.js: JavaScript library for creating interactive charts in HTML5. Available at: \url{https://www.chartjs.org}}, provides dynamic visualization of the data through real-time charts, interactive tables, and progress bars that facilitate the interpretation of monitored parameters.  

In addition, the system integrates security mechanisms and user management through JSON Web Token (JWT)\footnote{JSON Web Token (JWT): Open standard for secure user authentication. Available at: \url{https://jwt.io}} authentication, ensuring restricted access to the application. Furthermore, an automatic report generation module in PDF format and its delivery via email in case of error detection have also been implemented.  

The results obtained demonstrate that the proposed solution meets the established objectives: it enables real-time monitoring of different network devices, detects anomalies in their operation, and presents information in an accessible and comprehensible way. This system represents a valuable support tool for the management of telecommunication networks, with potential for extension to more complex environments.
