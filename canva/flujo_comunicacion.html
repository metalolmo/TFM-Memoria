Flujo de comunicación del sistema de monitorización

Usuario
Frontend (Vue.js)
Backend (FastAPI)
Routers Cisco (SSH)
Interacción
El usuario selecciona un router o una opción de monitorización.
➡
Petición HTTP
Vue.js envía una petición GET/POST mediante Axios al endpoint REST correspondiente.
➡
Validación y lógica
FastAPI valida el token JWT, consulta la configuración del router y prepara la operación.
➡
Sesión SSH
El backend abre una sesión SSH con Paramiko y ejecuta comandos IOS (show ip interface brief, show interfaces, etc.).
⬅
⬅
Procesamiento
FastAPI analiza la salida del router y genera una respuesta estructurada en formato JSON.
⬅
⬅
Actualización de la interfaz
Vue.js recibe el JSON, actualiza tablas y gráficas (Chart.js) y muestra el estado actual de las interfaces y errores.
Mediante un temporizador (setInterval), el frontend repite periódicamente el ciclo de petición–respuesta para mantener la información de monitorización actualizada.
