Arquitectura general del sistema

Capa de presentación (Frontend)
Navegador web del usuario
  • Aplicación web desarrollada en Vue.js.
  • Diseño responsivo con Bootstrap.
  • Consumo de API REST mediante Axios.
  • Visualización de tablas y gráficas de monitorización.
⬇
Capa lógica y de procesamiento (Backend)
Servidor FastAPI
  • Servicios REST implementados con FastAPI.
  • Gestión de sesiones SSH con Paramiko.
  • Autenticación y autorización mediante JWT.
  • Procesamiento de métricas y generación de respuestas JSON.
  • Generación de informes PDF y envío por correo electrónico.
⬇
Capa de dispositivos monitorizados
Red de routers Cisco en GNS3
  • Routers Cisco simulados en el entorno GNS3.
  • Acceso seguro mediante protocolo SSH.
  • Ejecución de comandos IOS (p.ej., show ip interface brief).
  • Obtención de estadísticas de tráfico, estado y errores.
