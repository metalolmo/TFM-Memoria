Especificación de Endpoints del Backend

Sistema web de monitorización de red – API REST basada en FastAPI

1. Autenticación y control de acceso
POST /register
Registro de usuario con almacenamiento seguro de credenciales y envío de enlace de confirmación por correo electrónico.
POST /login
Inicio de sesión. Devuelve un token JWT que debe incluirse como Bearer Token en peticiones posteriores.
GET /confirmar-correo?token=...
Confirmación del correo electrónico mediante token de verificación.
2. Monitorización de interfaces
GET /interfaces
Lista global de interfaces de todos los routers monitorizados.
GET /interfaces/{router_id}
Interfaces de un router específico con IP, estado y descripción.
GET /interfaces/{router_id}/detalles
Información detallada por interfaz: tráfico, errores, velocidad y dúplex.
GET /interfaces/errors/{router_id}
Devuelve únicamente interfaces con errores detectados.
3. Acciones sobre interfaces
POST /interfaces/{router_id}/{if}/shutdown
Deshabilita una interfaz de red de forma remota.
POST /interfaces/{router_id}/{if}/noshutdown
Habilita una interfaz previamente deshabilitada.
PATCH /interfaces/{router_id}/{if}/description
Modifica la descripción de una interfaz.
PATCH /interfaces/{router_id}/{if}/ip
Modifica la dirección IP y la máscara de una interfaz.
4. Estado y recursos del router
GET /router/{router_id}
Información general del router (modelo, versión, uptime, memoria).
GET /resources/cpu/{router_id}
Uso de CPU (5 segundos, 1 minuto y 5 minutos).
GET /resources/memory/{router_id}
Uso de memoria total, usada y libre.
GET /ping/{router_id}
Verificación básica de conectividad con el router.
5. Alertas e informes
GET /monitorizar-errores/{router_id}
Detecta nuevos errores en interfaces y, si existen cambios, genera un informe y lo envía por correo al usuario autenticado.
Nota: la generación del informe se ejecuta como tarea en segundo plano.
