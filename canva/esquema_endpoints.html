Al pulsar el botón se descargarán varios PNG: Autenticación, Interfaces, Monitorización, Estado/Recursos y Administración. Cada imagen tiene fondo blanco y se exporta con ancho fijo para insertarla como figura en la memoria.

Diseño de la API — 1) Autenticación

Endpoints para registro, login y confirmación de correo. Formato de intercambio: JSON.

Formato: JSON Acceso: Público
Endpoint Descripción Request (ejemplo) Response (ejemplo)
POST/register Registro de usuario y envío de enlace de confirmación por email.
{ "email": "usuario@dominio.com", "password": "********" }
{ "mensaje": "Usuario creado. Revisa tu correo para activarlo." }
POST/login Login y obtención de token JWT (Bearer).
{ "email": "usuario@dominio.com", "password": "********" }
{ "access_token": "<jwt>", "token_type": "bearer" }
GET/confirmar-correo?token=<jwt> Confirmación del correo a partir del token. —
{ "mensaje": "Correo confirmado correctamente. Ya puedes iniciar sesión." }

Diseño de la API — 2) Interfaces de red

Consulta y diagnóstico de interfaces (listado, detalle, errores) y acciones remotas sobre interfaces.

Routers: R1 · R2 · R3 Nota: en path, “/” se codifica como %2F
Endpoint Descripción Request (ejemplo) Response (ejemplo)
GET/interfaces Listado agregado de interfaces (todos los routers): IP + estado físico/protocolo. —
[ { "router": "R1", "ip": "192.168.56.11", "interfaces": [ { "nombre": "FastEthernet0/0", "direccion_ip": "192.168.1.1", "metodo": "manual", "estatus": "up", "protocolo": "up" } ] } ]
GET/interfaces/{router_id} Interfaces de un router incluyendo descripción por interfaz. Path: router_id Devuelve objeto con interfaces[] y campo descripcion.
GET/interfaces/{router_id}/detalles Diagnóstico profundo (UP/UP): tráfico, errores, BW/MTU y dúplex. Path: router_id Incluye trafico_in, trafico_out, errores, velocidad, duplex.
POST/interfaces/{router_id}/{nombre}/shutdown Deshabilita administrativamente una interfaz. Path: router_id, nombre (p.ej. FastEthernet0%2F1) Devuelve salida CLI (salida).
POST/interfaces/{router_id}/{nombre}/noshutdown Habilita administrativamente una interfaz. Path: router_id, nombre (p.ej. FastEthernet0%2F1) Respuesta análoga a shutdown.
PATCH/interfaces/{router_id}/{nombre}/description Modifica la descripción de la interfaz.
{ "descripcion": "Enlace a switch planta 2" }
 Incluye salida CLI y descripción aplicada.
PATCH/interfaces/{router_id}/{nombre}/ip Modifica IP y máscara de la interfaz.
{ "nueva_ip": "192.168.56.50", "mascara": "255.255.255.0" }
 Devuelve mensaje + salida CLI.
GET/interfaces/errors/{router_id} Devuelve únicamente interfaces con errores > 0 (entrada/salida). Path: router_id Devuelve errores_interfaces[].

Diseño de la API — 3) Monitorización, alertas e informes

Detección de nuevos errores y envío de informe PDF por correo al usuario autenticado (BackgroundTasks).

Acceso: JWT (explícito en el endpoint) Modo prueba: simulado=true
Endpoint Descripción Request (ejemplo) Response (ejemplo)
GET/monitorizar-errores/{router_id} Compara errores actuales vs previos; si hay cambios y existen errores, genera un PDF y lo envía por email. Recupera el destinatario desde el usuario autenticado (get_current_user). Path: router_id
Query: simulado (bool)
{ "errores": [ { "interfaz": "FastEthernet0/1", "errores_entrada": 3, "errores_salida": 2 } ] }
El endpoint está definido en un APIRouter y se añade al servidor con app.include_router(router).

Diseño de la API — 4) Estado del router y recursos

Endpoints para información general, CPU/RAM, conectividad, uptime y tráfico agregado.

Routers: R1 · R2 · R3 Diagnóstico: show version / show processes / show interfaces
Endpoint Descripción Request (ejemplo) Response (ejemplo)
GET/router/{router_id} Información general (modelo, versión, uptime, CPU, memoria, nº interfaces). Path: router_id Campos: modelo, version, uptime, cpu, memoria, interfaces.
GET/resources/cpu/{router_id} CPU utilization (5s/1m/5m) parseada por regex. Path: router_id Campos: cpu_5s, cpu_1m, cpu_5m.
GET/resources/memory/{router_id} Uso RAM (Processor Pool): total/usado/libre y % usado. Path: router_id Devuelve objeto memoria con total/usado/libre/porcentaje.
GET/ping/{router_id} Comprueba conectividad mediante ping al router. Path: router_id Devuelve activo (bool).
GET/uptime-summary Resumen de uptime para todos los routers. — Lista con router, ip, uptime.
GET/traffic-summary/{router_id} Resumen de tráfico total input/output y detalle por interfaz (packets). Path: router_id Devuelve trafico_total y detalle_interfaces.

Diseño de la API — 5) Administración y cambios de configuración

Endpoints para aplicar cambios remotos (hostname, timeout) y guardar configuración.

Operación: SSH + comandos IOS Persistencia: write memory
Endpoint Descripción Request (ejemplo) Response (ejemplo)
PATCH/router/{router_id}/hostname Cambia el hostname del router (configure terminal → hostname).
{ "nuevo_hostname": "R1-CORE" }
 Devuelve salida CLI en resultado.
PATCH/router/{router_id}/timeout Configura exec-timeout en líneas VTY 0–4.
{ "minutos": 10, "segundos": 0 }
 Devuelve salida CLI en resultado.
POST/router/{router_id}/save-config Fuerza guardado de la configuración (write memory). — Devuelve salida en resultado.
